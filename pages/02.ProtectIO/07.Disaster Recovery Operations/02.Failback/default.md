! Updated on 05/16/2023

Once primary site is restored and operational, you can restore the virtual machines to primary site using **FAILBACK** option

##### **Procedure**
1. From the left navigation, select **Primary Site**
2. On the right side, go to **Failback** tab
3. NEXT, Click on the **FAILBACK** button
4. Clicking **FAILBACK** button will show the confirmation dialogue box. Click **YES** to run the failback operation


##### Monitoring failback
You can monitor the failback process in ProtectIO UI as soon as failback operation is initiated.
