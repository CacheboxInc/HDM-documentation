! Updated on 05/16/2023

You can run **failover** operation in disaster recovery situation.

##### **Procedure**
1. From the left navigation, select **Primary Site**
2. On the right side, go to **Failover** tab
3. NEXT, Click on the **FAILOVER** button
4. Clicking **FAILOVER** button will show the confirmation dialogue box. Click **YES** to run the failover operation


##### Monitoring failover
You can monitor the failover process in ProtectIO UI as soon as failover operation is initiated.
