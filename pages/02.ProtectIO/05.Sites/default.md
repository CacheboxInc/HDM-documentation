! Updated on 05/16/2023

After logging on to ProtectIO DRaaS platform User Interface for the first time, the **Sites** page is displayed.  

Sites page shows the list of Primary and Disaster Recovery Sites of the logged in tenant.  
Use below tabs on the Sites page to access specific information or to perform certain operations
+ **CDP Configuration**: Shows the list of CDP configurations created for protecting virtual machines. 
+ **Virtual Machines**: Shows the list of all protected virtual machines from primary site
+ **Failover**: Tenant admin can initiate failover process from this tab. This tab is available only for primary sites.
+ **Failback**: Tenant admin can initiate failback process from this tab. This tab is available only for primary sites.
