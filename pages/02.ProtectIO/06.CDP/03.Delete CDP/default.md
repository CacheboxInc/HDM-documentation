! Updated on 05/16/2023

When you no longer need a CDP policy, you can delete it.

>>>> ● &nbsp; When you delete a CDP policy, you are also deleting ALL data associated with it, forever. <br> ● &nbsp; You should not delete a CDP configuration if failover/failback process is in progress.


##### **Procedure**
+ From the left navigation, select **Primary Site**.
+ On the right side, select **CDP Configuration** tab.
+ Select the CDP Policy from the list.
+ Click on **DELETE** button which will open a confirmation dialogue box.
+ In the Delete CDP Configuration dialog box, verify that you want to delete this policy.
>>>> When you click YES, all data associated with protected VMs under the selected policy is deleted permanently, forever, and are not retrievable.
+ Click **YES** to delete the CDP configuration and associated data.
